# CarbonFarm

> CarbonFarm Technology is a French climate-tech company (Nanterre, SIREN 912160389) that uses
> satellite imagery and machine learning to monitor, measure and verify greenhouse-gas reductions
> in rice production. Rice accounts for roughly 12% of global methane emissions; CarbonFarm
> remotely detects the water-management and straw-management practices that reduce them — notably
> Alternate Wetting and Drying — so that carbon-credit MRV can be done at paddy level without
> relying on self-declared paper logbooks.

This file was GENERATED by API Evangelist from the artifacts in this repository. CarbonFarm does
not publish an llms.txt — https://carbonfarm.tech/llms.txt returns 404.

## What CarbonFarm sells

- Satellite + ML monitoring of rice farming practices at paddy level
- Baseline and project emissions estimation using scientifically validated models
- Additionality verification for rice carbon-credit projects (digital MRV / dMRV)
- A client platform for initiating, monitoring and verifying decarbonisation projects

Publicly named customers and partners include Mars Food, Tilda, Beneo, Amru Rice, Vida Energy,
Fortune Rice, Ostrom Climate, Core Carbon X, the Sustainable Rice Platform, UNDP, Danone,
Rikolto, Cornell University, IRRI, Regrow Ag and Australia's Department of Foreign Affairs and
Trade. Seed funding of €2.5M / $2.6M was raised with participation from Racine2, TechMind,
Ponderosa, AgFunder, Climate Capital and BPI France.

## APIs

CarbonFarm operates no developer program. There is no developer portal, no API reference, no
getting-started guide, no SDK and no public API product. One machine-readable contract exists:

- [CarbonFarm CMS Content API](https://cms.int.carbonfarm.app/server/specs/oas): the Directus
  10.10.7 headless CMS behind carbonfarm.tech's news posts and images. OpenAPI 3.0.1, 14
  operations. Auto-generated from the live schema, not published as a developer contract.
  Internal infrastructure — the data endpoints return 403 anonymously.

The rice MRV platform at https://app.carbonfarm.tech is gated: every path 301/302s to an Auth0
organization login. No API contract is published for it.
